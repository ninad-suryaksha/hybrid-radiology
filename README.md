# An Intelligent Radiologist Assistant

Hybrid CNN–Transformer segmentation of chest radiographs with region detection and multi-method explainability.

**Authors:** M Ninad Suryaksha, J Mohammad Mudassir, Anupal Maji  
**Affiliation:** Department of CSE, Alliance University, Bengaluru, India  

## Project Overview
This repository hosts the interactive 20-slide presentation showcasing:
1. Executive Summary & Clinical Context
2. Problem Space & Challenges in Chest Radiography
3. System Architecture & Methodology (Hybrid CNN–Transformer)
4. Region Detection & Dual-Encoder Design
5. Multi-Method Explainability (Grad-CAM, Integrated Gradients, Attention Rollout)
6. Evaluation Results, Validation Metrics, & Benchmarks
7. Clinical Workflow Integration & Next Steps
